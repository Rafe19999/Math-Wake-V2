# MathWake V1.7 — Custom Alarm Ringtones

Based directly on V1.6 classic step-counting and countdown mode. Step logic, math challenge, appearance and logo retained.

**New:** Select any Android-supported downloaded audio file from the system picker (MP3, WAV, etc.), save persistent access to the selected file, display its name, reset to the default tone, and loop it when the alarm sounds. If the file is deleted or becomes inaccessible, the app attempts to use the system alarm tone.

## Build APK
Upload the contents of this ZIP to the root of a GitHub repo. `.github/workflows/build-apk.yml` is included. In GitHub Actions, trigger **Build MathWake APK**, then download the artifact ZIP.

The project has not been compiled or tested on a physical device in this environment. Do a short test alarm after installing. Do not rely on this experimental build as your only wake-up alarm.
