# MathWake V1.6 Classic Counting

Restores the earlier V1.2 step detection (Step Counter when available; Step Detector otherwise). Keeps the V1.5 countdown 40 -> 0 and updated dark UI and logo.

Note: This restores previous behavior, **not a true-walking verification**. Hand shaking can be counted as steps by the Android hardware sensor. Batching/delays may remain. Keep a backup alarm while testing.

Build with the included GitHub Actions workflow.
